
MiniVFS – A Mini Virtual File System in C

Project description : 
MiniVFS is a custom virtual file system developed in C to understand the internal working of file systems and operating-system-level file management.

The project implements core file-system concepts such as inodes, file tables, file descriptors, data blocks, superblocks, file permissions, and file operations.

Key features:
📁 File creation, deletion, opening and closing
📖 Read, write and seek operations
🧩 Inode-based file management
📋 System-wide file table and per-process file table
💾 Data block management
🔐 File permissions and access modes
⚙️ Superblock and file-system metadata management
🖥️ Custom APIs for interacting with the virtual file system

Technologies : C, Data Structures, File I/O, Operating System Concepts, Linux

Key learning : Understanding how operating systems manage files internally and how components such as inodes, file tables, file descriptors and data blocks work together.
